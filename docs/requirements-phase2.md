## 1. 背景・目的

前回作成した「ことば×イラスト」形式のマッチング教材自動生成ツールを拡張する。
先生が教材作成前にマッチングの形式（モード）を選べるようにし、あわせて新しいモード（イラスト×イラスト／イラスト×漢字）とヒント機能を実装する。

## 2. 今回のスコープ

### 2.1 今回やること

**① モード選択画面の追加**

- テーマ入力の前に、先生がマッチングのモードを選ぶ画面を新設する
- 選択肢は以下の3つ（カード形式などで並べて表示）
  1. ことば×イラスト（既存機能）
  2. イラスト×イラスト
  3. イラスト×漢字

**② 3モードすべての実装**

1. **ことば×イラスト**（既存機能を踏襲）
   - テーマ入力 → ことば生成（Gemini API）→ イラスト取得 → プレビュー → 印刷レイアウト出力

2. **イラスト×イラスト**（新規）
   - 同じテーマについて、作風の異なる2種類のイラストを用意し、それらをマッチさせる
   - 例：フォトリアル風のイラストと、シンプルな線画イラスト風の2種類を生成・取得し、意味が対応するペアを作る
   - 画像の生成・取得は「4. イラスト取得ロジック」に準じる

3. **イラスト×漢字**（新規）
   - イラストの意味に対応する漢字をAIが自動選定し、マッチング教材を作る
   - 特別支援学級は学年と習熟度が一致しないことが多いため、学年別漢字配当表には縛られない自由選定とする

**③ ヒント機能の実装**

- イラストの下（中央下部）に、小さく対応することば（またはヒントとなる文字）を表示するオプション
- オン・オフは教材全体で一括設定（作成前のモード選択・設定画面でまとめて決める）

**④ イラスト取得ロジックの変更**

- 詳細は「4. イラスト取得ロジック」を参照

### 2.2 今回やらないこと（後日）

- 先生が使いたいことば・漢字を直接指定できる入力欄（テーマ入力だけでなく、個別の語彙をピンポイントで指定する機能）
- この機能に関する正式な仕様の最終合意（先生側との確認等）

## 3. モード選択・設定画面の要件

テーマ入力の前に、以下を1画面で設定できるようにする。

- マッチングモードの選択（①ことば×イラスト／②イラスト×イラスト／③イラスト×漢字）
- ヒント表示のオン・オフ（教材全体で一括）
- 対象年齢、ペア数など、既存項目はそのまま維持

## 4. イラスト取得ロジック（詳細・Claude Code向け指示）

### 4.1 基本方針

イラストが必要な場面では、**原則としてPollinations AIを最優先**で使用する。

- 理由：無料・APIキー不要で、URL形式で即座に呼び出せるため
- 呼び出し例：`https://image.pollinations.ai/prompt/{テキスト}`
- プロンプトには必ず絵柄統一のための指定語を含めること
  - 例：「シンプルな線画」「flat illustration, simple line art, for children」

### 4.2 例外（イラスト×イラストモードの「リアル画像」側のみ）

「イラスト×イラスト」モードにおける**リアル画像側のみ**、以下の優先順位で取得する。

1. **Pixabay API** で検索（実在の写真・イラスト素材）
2. 見つからない場合、**Iconify API** で検索（オープンソースのアイコン素材。`prefixes` パラメータで絵柄セットを絞り込み、絵柄の不統一を防ぐ）
3. 両方失敗した場合のみ、**Pollinations AI** にフォールバックして生成

### 4.3 モード別の取得ロジックまとめ

| モード | 画像の種類 | 取得順序 |
|---|---|---|
| ことば×イラスト | イラスト1種 | Pollinations AI（最優先） |
| イラスト×イラスト | リアル画像側 | Pixabay → Iconify → Pollinations AI（フォールバック） |
| イラスト×イラスト | 線画イラスト側 | Pollinations AI（最優先） |
| イラスト×漢字 | イラスト1種 | Pollinations AI（最優先） |

### 4.4 全失敗時のフォールバック

すべての取得方法が失敗した場合は「イラストが見つかりませんでした」のプレースホルダーを表示する。

## 5. 技術構成（更新）

- フロントエンド：React（bolt.newでプロトタイプ→Cursor + Claude Codeで実装）
- ことば・漢字生成：Google Gemini API（無料枠中心）
- イラスト取得：Pollinations AI（原則最優先）／Pixabay API → Iconify API → Pollinations AI（イラスト×イラストのリアル画像側のみ）
- サーバー：Vercelのサーバーレス関数
- データベース：不要（保存が必要な場合のみlocalStorage）
